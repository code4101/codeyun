# Code4101的天道系统

`Code4101的天道系统`是基于 BepInEx 6 的《造化仙缘》综合 Mod。游戏内简称“天道系统”，设置入口简称“天道”。源码保存在 CodeYun，游戏原始 DLL 和存档文件均不直接修改。

## 当前功能

- `丹谱`：按游戏品阶折叠展示全部丹方，点击后复用游戏左下角的丹方详情。
- `智能`：读取当前丹方、已装备丹炉和全局药材目录，在插件内离线求解可摆放方案；背包库存只投影“是否可用”，不限制静态解空间。
- 智能求解先按目标五行分为纯净解、单一额外属性补偿解、完整兜底解；阶段内按目标属性覆盖度优先，并以药材种类数迭代加深枚举形式，保证先完整检查单药、双药等简单组合，再用联合整数方程反解数量。数量向量不会直接视为独立成品解：同一药材结构先按丹方规则阈值归入数量族，只保留种植时间、阴阳占格和总件数互不支配的少量代表，再进入旋转与几何装箱。阶段完成后若已有背包可用解，就不再进入更低优先级阶段。
- 方案按阶段、丹药品质、每丹种植时间、累计种植日数、药材总数做稳定排序；同一药材 ID 集合只保留最终价值最高的数量、阴阳与布局变体。“仅看可用”只过滤缺料方案，不改变剩余方案顺序。
- 丹炉、丹方与静态药材配置对应的结果会写入游戏用户目录中的可再生缓存；库存变化只重新计算可用标记，配置或求解器版本变化会自动换用新缓存键。
- 智能求解运行在独立后台线程；游戏主线程只采集输入快照、轮询完成状态并展示结果。切换丹方会发送取消信号并丢弃旧版本结果，离开智能页则允许后台继续计算。
- 求解结果沿用官方方案卡片，每批展示 5 条；点击方案只回填炼丹格，不会自动炼丹。
- 方案最终成丹数与品质按游戏原生顺序执行已激活炼制天赋和丹炉效果，再叠加丹方基础值与图形规则；方案卡片以“成本：每丹种植时间 5.00 天”的独立行展示，按总种植天数除以最终成丹总数计算，超过 300 天时按 360 天/年换算。
- 不依赖 CodeYun 服务、浏览器、`localhost` 或联网 API，可单机分发运行。
- `天道试炼`：在游戏 `设置` 页面提供与 `游戏 / 视频 / 声音 / 键盘` 同级的 `天道` 配置页；主角不受影响。
- `炼丹助手`：在天道配置页动态开启或关闭 `丹谱 / 智能` 炼丹功能，默认开启。
- `NPC 属性倍率` 调整气血、术攻/术防、物攻/物防、护甲、护罩；`速度倍率` 默认关闭，开启后速度使用同一倍率。
- 倍率最低为 `×1`，不设插件上限；极端倍率仍受游戏底层数值类型限制。
- 倍率在游戏完成原有难度、境界压制等计算后乘到 NPC 最终面板，不遍历或改写 NPC 基础属性。
- 精力与神魂始终不放大。
- 天道配置保存为插件级全局设置，可在主菜单修改，所有存档共用并在运行中立即生效。
- 配置文件位于 `BepInEx/config/code4101.zaohua.tiandao.cfg`，按 `天道试炼 / 天道助缘` 分节并带配置版本；新增功能可追加参数而不破坏旧配置。
- 储物空间为丹药提供“全部 / 丹药 / 丹方”二级筛选，为装备提供“全部 / 头饰 / 服饰 / 鞋履 / 饰品”二级筛选，并跟随游戏原有“记住筛选”开关。
- 储物空间原生排序菜单追加“名称排序”，按当前语言环境比较物品名称；重复选择可切换升序和降序。
- 装备区提供按存档隔离的活动方案下拉框；`方案1` 首次自动接管原有装备，新建方案从六个空槽开始配置。当前方案内的穿戴与卸下会自动持久化，切回时恢复该方案的最新状态。下拉列表只负责选择方案；当前方案标题右侧集中提供“改名 / 删除”，删除需再次点击确认，且至少保留一个方案。
- 配装槽位以装备的稳定 `BlendId.sedId`（物品配置 ID）绑定；`blendEnum` 只是数据表类型，背包实例 `packId` 只用于同配置多件时优先找回原实例。方案文件使用可往返校验的 JSON 协议持久化；切换前会先解析全部非空槽位，任一目标未找到就取消整次切换并保持当前装备不变。
- 功法配置悬浮框会显示当前功法图形规则的实际倍率，例如“当前增幅 ×2”。倍率直接调用游戏刷新丹田布局时使用的原生 `GetUpMultiplier` 计算，因此包括尚未生成运行时加成记录、但会在战斗事件中执行效果的规则；不展示 `UpdateAction` 等内部动作文本。
- 丹田配置页提供“优化排布”：保持当前已选择的功法、术法和神通不变，在合法格位与旋转中限时搜索更优布局。默认目标为最大化所有图形规则的 `(1 + 当前增幅)` 乘积，同分时优先总增幅更高；评分复用游戏原生倍率算法。“上方”等方向规则按游戏原生的区域相交语义计算，不要求整个图形落入区域。搜索先做单件全候选爬山，再以均匀摆位、多件扰动和阈值进度引导跨越“每 N 个才 +1”的同分平台。应用失败会恢复原布局，并在 BepInEx 日志中记录每条规则配置、优化前后倍率、候选解和应用结果。
- 装备方案数据保存在 `Application.persistentDataPath/Code4101.Tiandao/equipment-loadouts.json`，不修改官方存档、不写项目目录，并使用同目录临时文件原子替换。
- 背包属性区和战斗单位生命条的数值达到 `1万` 后自动压缩为“万”，达到 `1亿` 后压缩为“亿”；压缩值按量级保留四位有效数字，生命条左右两值分别判断，底层属性值不变。

## 构建与部署

游戏默认目录为 `D:\SteamLibrary\steamapps\common\GodWorld`。

```powershell
.\tools\zaohua_mod\build.ps1
.\tools\zaohua_mod\deploy.ps1
```

完全退出并重启游戏后验证：

1. 主界面点击“再寻仙踪”。
2. 进入顶部 `K` 炼丹入口，再进入“炼制丹药”。
3. 右侧依次出现 `丹方 / 炼制 / 配方 / 丹谱 / 智能`。
4. `BepInEx\LogOutput.log` 包含 `Code4101 Tiandao patches registered.`。
5. 打开 `设置`，点击左侧 `天道`，可配置 `NPC属性倍率`、`速度倍率` 和 `炼丹助手`；底部 `恢复默认` 会恢复为 `×1 / 关闭 / 开启`。

Steam 文件校验不会修改 CodeYun 中的源码；插件部署产物位于 `BepInEx\plugins`。游戏或 BepInEx 更新后应重新构建并按上述真实入口验证兼容性。
