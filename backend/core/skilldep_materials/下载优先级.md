# SkillDep 素材下载优先级

来源：CodeHub（Mac）主体转达、用户授权，2026-10-22 起执行。之后的 SkillDep 素材下载都照这份规则安排。

## 分工

- 百度网盘整理和爬虫都在 mf（codepc_mf）上做。
- 素材只落在 `F:\CodeYun\materials\m2610skilldependency\<素材 id>\`。
- 进度照旧用 `PUT /api/data-platform/skill-dependency/plan/materials/{id}/acquisitions/{设备}` 回报到 CodeHub（客户端是 `codehub.py` 的 `CodeHubSkillDep`）。

## 顺序

1. 拉素材清单 `GET /api/data-platform/skill-dependency/plan/materials`，每条带 `points`（二级技能点）和 `priority`。`priority = 0`（没有三级用到）的放到最后下，或者不下。
2. **① 网盘先收藏**：收到网盘链接后，先转存到自己的网盘，再登记网盘转存（`put_cloud_transfer`）。
3. **② 按二级平衡**：每个二级先下 priority 最高的 1 条保底。网盘里收藏了不算已有资源，落到 mf 本地才算。
4. **⑤ 其余按优先级**：保底完成后，剩下的按 priority 从高到低下。
5. **③ 慢来源单独一路**：限速慢的来源（百度网盘非会员限速、`research/site_blocks.json` 里限过流的网站）单独走一路，在后台最先开跑，不占正常顺序。
6. **④ 超大包先下一部分**：超过 50GB 的包，按时效先下最新的约 2GB，登记 `status=partial`，并在 `scope` 里写清下了哪部分；等所有二级都有资源后再补整包。

## 限速

- 同一网站串行，间隔要像真人：一般 ≥10 秒，电商 2–5 分钟。不同网站可以并行。
- 遇到限流（403/429/412、"访问过于频繁"、没有提示的空白页）时，立即停掉该站的全部爬虫，冷却 24 小时，并用 site_guard 记录。
