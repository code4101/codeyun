# SkillDep 素材下载规则

来源：CodeHub（Mac）主体转达、用户授权，2026-10-22 更新，替换旧版。之后的 SkillDep 素材下载都照这份规则做。

## 分工与落点

- 百度网盘整理和爬虫都在 mf（codepc_mf）上做。
- 素材落在 `F:\CodeYun\materials\m2610skilldependency\<素材 id>\`。
- 接口在 CodeHub `/api/data-platform/skill-dependency/plan` 下，客户端是 `codehub.py` 的 `CodeHubSkillDep`（地址、令牌取灵网 CodeHub 对端配置）：
  - `GET /materials`（`materials()`）：`priority` 越大越先下；`tier` 1=第 1 版必需、2=其余有需求、0=没有三级用到（最后或不下）；`first_batch_points`=它服务的第 1 版三级；`first_batch_limit_mb` 有值时这一轮只下这么多；`demand`=需求分。
  - `GET /first-batch`（`first_batch()`）：第 1 版选中的三级及各自用到的素材。
  - `GET /site-blocks`（`site_blocks()`）：站点熔断记录，`active=true` 的站点任何设备都不许访问。
  - `PUT /site-blocks/<站点短名>`（`put_site_block()`），body `{"reason": "..."}`，默认冷却 24 小时。站点名用主域名短名，如 `cninfo`、`taobao`、`ccgp`（`site_guard.site_name()` 计算）。
  - `PUT /materials/<id>/acquisitions/<设备 id>`（`register()`）：下载登记。

## 顺序

1. 收到网盘链接先转存到自己网盘并登记网盘转存（`put_cloud_transfer`）。网盘收藏不算已下，落到 mf 本地才算。
2. 按 `priority` 从高到低下。priority 每次下完会重算，每批开始前重新拉清单（`batch.next_batch()`，CLI `uv run python -m backend.core.skilldep_materials.batch --limit 10 --tier 1`）。"每个二级都要有""大包先下一部分"已算进 priority，不另外处理。
3. `via=buy`、需要登录或付款的不进正常批次，列出来另行处理。
4. 限速慢的来源（百度网盘非会员、`/site-blocks` 里限过流的站）单独一路后台先跑，不占正常顺序。

## 爬虫做法

- 启动前查 `/site-blocks`，站点熔断中就不访问（`site_guard.assert_open()`）。
- 遇到限流（403/429/412、"访问过于频繁"、无提示空白页）立即 `PUT /site-blocks/<站点>` 熔断，并停掉该站全部爬虫（`site_guard.trip()`）。
- 验证码不是限流：先试一次，不行就停下报告，不熔断、不绕过。要登录、要付费的跳过并记下。
- 一站一路：同一网站串行，间隔像真人（一般 ≥10 秒，电商 2–5 分钟），搜索词、翻页别套同一模板；不同网站各开一路并行。
- 批量入口优先：官方接口、批量下载、数据集文件 > 结构统一的列表页翻页 > 逐页打开。
- 第 1 版只取够用的：`first_batch_limit_mb` 有值的只下这么多，按时效取最新（公告按日期倒序、统计取最近年份），优先取和 `first_batch_points` 里三级相关的部分。
- 空内容不算：返回 200 但 JSON 数据数组为空、正文去掉脚本样式后少于约 200 字、或文件小于 1KB 的，不计入素材，不登记 downloaded/partial，保持 downloading 并在日志写明（`page_set.empty_reason()`）。接口有时间窗限制（如 chinamoney LPR 只给一年）时按段分批查。
- JS 渲染页：先用受控浏览器（DrissionPage，无头）打开页面监听 XHR/Fetch，找到数据接口后直接请求接口（同站串行、间隔照旧）；接口用不了再用 DrissionPage 渲染后取链接和正文。无头浏览器不占桌面焦点，不需要 GUI 租约。
- 可续传：每个文件下完写进素材目录的 `manifest.json`（来源 URL、sha256、大小），重跑跳过已有的。

## 登记

- 开始登记 `downloading`，每下完一批更新 `size_bytes`（已落盘累计字节）。
- 完成登记 `downloaded`；只下一部分登记 `partial`，并在 `scope` 写清范围；失败登记 `failed`，写原因。
- `partial` 只用于已下到真实内容（正文、附件、数据文件）的一部分，`scope` 写清下了哪些；只拿到来源入口页、栏目首页、列表页时保持 `downloading`（CodeHub priority 把 partial 当作已有素材）。`page_set` 把素材 `url` 当入口页，只有入口页时自动保持 downloading；`--expand N` 从入口页展开正文和附件。
- 每批用 `batch.py --launch` 启动（按站点一个后台进程，站内串行、站间并行），自动写 `F:\CodeYun\materials\m2610skilldependency\_batches\<时间戳>.json`（名单、PID、日志、跳过原因）。
- 已有工具：直链 `acquire.py`、列表接口 `listing_crawl.py`、进度 `progress.py` 都按上面规则查熔断、登记熔断和登记状态。
