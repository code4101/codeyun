# 前端交互约定

## 侧边导航

- 侧边栏分组标题可以保留图标，例如“综合工具 / 游戏工具 / 笔记工具 / 集群管理”。
- 分组下的一级功能项默认不额外放图标，保持纯文字列表，避免同层级视觉噪声过大。
- 新增工具页时，若放在“综合工具”等一级分组下，默认沿用“无图标菜单项”；只有确实存在强识别需求时再单独讨论例外。

## 顺序调整

- 只要功能目标是“调整顺序”，默认交互优先使用拖拽排序。
- 拖拽应尽量提供明确的拖拽手柄，不依赖整行任意区域拖动，避免误触编辑控件。
- `上移 / 下移` 按钮不作为默认方案，除非场景确实不适合拖拽。
- 候选项、展示项、配置项如果都涉及顺序，默认应共享同一套顺序来源，避免不同界面顺序漂移。

## 当前已落地场景

- 笔记自定义属性排序：拖拽
- 图片浏览排序规则：拖拽
- 类型管理顺序：拖拽
