# 可验证所有权租约与双向通信设计（历史归档）

本文原先用于解释凡修旧版 owner JSON、租约和 Kernel 内部锁。该实现已经删除，不能再作为凡修运行架构依据。

凡修当前唯一事实源是 [凡修行为树运行框架约定](./凡修行为树运行框架约定.md)：

- Kernel 只接收并执行普通 Cell。
- interrupt、restart、shutdown 使用原生 Jupyter 生命周期。
- Scheduler、优先级和模拟器独占仲裁全部位于 Kernel 外部。
- Kernel 内没有 owner JSON、manual queue、来源锁或 Scheduler 锁。

“可验证所有权租约”仍可作为其他跨进程系统的一般设计备忘，但不得套回凡修 Kernel。凡修若需要资源仲裁，应在外部 Scheduler 的独立文档与实现中说明。
