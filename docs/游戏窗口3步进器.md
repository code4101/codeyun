# 数据标注步进器

这份旧入口已拆成两篇文档：

- [步进器-自动探索标注数据.md](步进器-自动探索标注数据.md)：简称“自动标注”，描述如何通过截图、OCR、拖拽探索和 AI/人工辅助补齐标注数据。
- [步进器-任务设计与调度规范.md](步进器-任务设计与调度规范.md)：简称“任务调度”，描述如何基于已有标注数据设计任务、识别场景、规划跳转和执行调度。
- [步进器-日常任务覆盖审计.md](步进器-日常任务覆盖审计.md)：记录新版日常定位预设对旧版凡修日常入口逻辑、状态语义和特殊风险的覆盖情况。
- [步进器-日常查找托管交接.md](步进器-日常查找托管交接.md)：给新会话/子 agent 的交接文档，记录当前目标、已落地内容、未完成风险和下一步优先级。
- [凡修运行态抓包观察事实层.md](凡修运行态抓包观察事实层.md)：记录抓包解析出的用户动态数据如何作为观察事实叠加到图鉴系统，而不是污染静态 catalog。
