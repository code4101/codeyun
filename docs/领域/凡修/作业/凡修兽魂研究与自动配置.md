# 凡修兽魂快捷合成契约

本页只保存当前代码仍引用的业务证据和危险动作边界，不再维护研究日记、UI 探索步骤或算法施工清单。

## 已验证合成策略

真实批次证明快捷合成失败会消耗完整批次且不产生升级魂晶，因此期望材料成本使用 `n / p`：

- 1～3 级：2 件、55%，允许精确匹配“当前成功率较低 / 是否确认进行合成”后确认。
- 4 级及以上：3 件、100%，不应出现低成功率确认。

这项规则由 `quick_synthesis_policy()` 和回归测试拥有；修改概率、批量或失败语义时必须先取得新的真实证据并同时更新代码与测试。

## 安全边界

- 锁定、上阵、保护集合和快捷合成排除项必须在动作前读取并保持。
- “仅计算”“生成计划”“执行一次并复核”是三个不同副作用等级。
- 不提供无预算、无保护、无回读的一键清仓。
- 每次真实合成后重新读取库存和结果；未知确认框或数量不一致立即停止。

装箱优化、旋转翻转、评分函数、缓存和 Runtime 字段属于代码内部实现，不向下游开放为操作文档。
