# 凡修动态插桩契约

## 边界

动态插桩属于接口层，只提供游戏运行态的结构化读取，不决定何时运行、如何调度或随后执行什么业务。

当前实现固定为 `strict-read-only`、失败关闭：

- 允许读取设备/进程身份、`/proc` 映射、进程内存、已保存数据包和数据库快照。
- 禁止 Frida 附加、注入、Hook、部署 Server、执行 Lua、初始化 Manager、替换方法或发送游戏网络命令。
- Runtime 不提交 Cell、不注册作业，也不读取 Scheduler 或行为树状态。

## 对外结果

业务读取必须返回：

- 稳定业务对象，而不是地址、偏移或脚本细节；
- `complete`、`observed_at`、来源与采集水位；
- 可区分的 `data_not_loaded`、缓存失效、版本不支持、解析缺陷和外部环境异常。

普通请求只走有界快路径。冷发现、广域扫描和缓存重建必须是显式诊断操作；不得藏在页面刷新或业务 API 中。

## 新鲜度

- 页面默认读取数据库快照，不自动访问游戏。
- “从游戏更新”只有在采集水位覆盖本次触发时间后才能返回成功。
- 数据未加载时，上层可用已验证 GUI 路径促成自然加载，再重新只读观测；Runtime 本身不得初始化对象。
- 失败时保留原数据库值，不以空结果或旧实例冒充当前事实。

- 路由：`backend/api/fanxiu/dynamic_instrumentation.py`
- 核心：`backend/core/fanxiu/instrumentation/`
- 当前能力与精确字段以代码、OpenAPI 和聚焦测试为准；本文不维护逐 Manager、地址链、业务样本或历史性能数字。
