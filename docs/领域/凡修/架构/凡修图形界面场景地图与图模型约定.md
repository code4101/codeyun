# 凡修图形界面场景图契约

## 识别模型

- Layer 0：当前业务明确声明的候选与可执行弹窗。
- Layer 1：人工设计的稳定导航枢纽。
- Layer 2：其余具有场景身份的 scene。
- Layer 3：没有身份 Shape 的相似参考，只能辅助 unknown 诊断，不能输出 scene id 或参与导航。

每张新直播帧完整执行 Layer 1 → Layer 2；没有可靠 scene 时才附加 Layer 3 信息。等待必须持续获取新帧，不能重复计算旧截图。

## 形状证据

- OCR、图像匹配、mask 和裁剪都属于 Shape 内部证据。
- 业务层不得读取全帧 OCR 后覆盖图模型结果、猜按钮或直接点击文字框中心。
- 缺少 scene、身份 Shape 或动作 Shape 时安全失败并保存证据，不建立私有识别旁路。

## 未知状态

- unknown 是当前没有可靠 Layer 0～2 scene id 的观测，不是一个可导航 scene。
- 已知 scene 缺路径属于资产缺陷，不能降级为 unknown。
- `#424` 只承载经过有界连续 unknown 观察后允许的低风险兜底动作；每次动作后重新观察。
- 禁止使用 Android Back 或 Esc 作为恢复动作。

## 弹窗

弹窗与业务候选进入同一次图裁决。只有同时具备可靠身份和可执行后继动作的弹窗才能插入处理；动作后回到同一业务候选重新识别。弹窗目录不构成第二套识别器。

## 导航

`go_scene()` 固定执行：

```text
识别当前 scene → 选择已标注 Shape → 执行动作
→ 读取真实落点 → 记录后继事实 → 从真实落点重新规划
```

`sceneJumpTarget` 是真实后继及频次，不是允许落点白名单。规划器一次只决定下一动作，不锁定完整路径。

## 资产写入

已有资产树标注默认只读。AI 可以读取、匹配、诊断、截图、计算分数和提出候选，但未经用户明确点名授权，不得修改已有 scene、Shape、识别关系、坐标、尺寸、标题、阈值、OCR 条件、mask、父子/继承关系、`sceneJumpTarget` 或资产树目录结构。

授权只覆盖当次点名的 scene、Shape 或字段，不得扩展到相邻标注或批量整理。获得授权后：

1. 保存当前真实帧和原标注摘要。
2. 只修改点名字段。
3. 用同一目标执行真实检测。
4. 报告实际变更字段和复验结果。

未获授权时，新发现只写系统临时目录中的诊断证据或人工确认候选，不写正式资产树。
