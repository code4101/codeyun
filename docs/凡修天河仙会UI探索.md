# 凡修天河仙会 UI 探索

## 当前结论

“天河仙会”是限时活动，入口位于世界场景 `#34` 左侧活动栏。本轮实测的转盘开放时间为 `08/10 00:00:10-08/12 23:59:35`，榜单开放至 `08/13 22:00:00`；这些时间属于动态活动数据，不能作为场景身份。

活动主流程分为五个固定页签：

1. **仙花宝盘**：消耗太初仙符转动宝盘；每次转动获得随机奖励、2朵太初玉棠和4个太初仙玉。
2. **排名**：按获赠玉棠数量排名，可查看榜单奖励。
3. **任务**：分“活跃”和“赠送”两类任务，产出太初仙符等活动资源。
4. **商店**：包含灵石礼包和付费礼包。
5. **兑换宝阁**：使用太初仙玉兑换活动商品。

主盘还包含位面选择、活动规则、赠送记录和奖励预览。位面列表是动态业务数据；本轮看到“云霞绚烂、春华秋实、纵横捭阖、潮起东方、稳操胜券、岁序更替、听风起雨”等位面名称，不应写入场景识别条件。

## 操作安全边界

- 导航页签、规则、位面、记录、奖励预览和查看奖励属于信息型操作，可以用于 UI 探索。
- “转动”“转动十次”“领取奖励”“回赠”、礼包购买和商品兑换会消耗资源或产生外部业务影响，探索阶段不得点击。
- 红点、“领”、数量、倒计时、玩家名、排名和活动货币均会变化，只能作为业务状态，不能作为场景身份。
- 返回必须点击页面左下角明确的返回图标或弹窗外已确认空白，不使用系统 Back/Esc。
