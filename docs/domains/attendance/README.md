# 考勤文档入口

考勤是由 CodeYun 控制层与 `xlproject/xlsln/kq5034` 业务运行时共同组成的独立业务域。进入本域后先分类，再读取本次任务需要的正文；不要把考勤细则复制到根 `AGENTS.md` 或全局上下文。

## 阅读顺序

1. [考勤课程 ABC 分类约定](考勤课程ABC分类约定.md)：先区分 A 类月课、B 类禅宗/修道班、C 类闯关。
2. [考勤公共接口](考勤脚本与表格接口.md)：确认 CodeYun、mf 执行环境和外部业务运行时的责任边界。
3. 按任务进入专项正文：
   - [课程工作簿月度生成](考勤课程工作簿月度生成规范.md)
   - [课程收尾](考勤课程收尾规范.md)

## 权威边界

- 代码、API schema、类型、函数 docstring 和测试定义当前实现契约。
- 本目录定义考勤业务分类、跨仓库边界和代码无法自解释的稳定规则。
- 操作参数不在文档重复维护；公共接口不能表达业务意图时，应修接口并补测试。
