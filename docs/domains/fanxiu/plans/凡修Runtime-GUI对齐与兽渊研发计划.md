## 决策与边界

- 日历只证明日期与活动行；活动卡片只通过自身分页窗口查找；“前往”只作用于已确认的当前卡片。
- Runtime 列表允许保留缺少静态名称的未知实体，但该实体不得参与 GUI 对齐；Runtime/静态类型冲突则整份失败关闭。
- 游戏操作只在 Scheduler 空闲窗口切换到 AI 运行权执行；静态代码、测试和只读缓存研究不占用工程作业窗口。
- 当前动态插桩严格只读，禁止 Frida、Hook、Lua 执行、Manager 初始化和游戏命令。
- Kernel manager 自身代码过期时必须整体替换；只重启 child Kernel 会复用旧 bootstrap，无法跨模块迁移恢复。
