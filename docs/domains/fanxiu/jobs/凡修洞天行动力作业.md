# 凡修洞天行动力契约

本页保留给 `backend/core/fanxiu/instrumentation/dongtian.py` 的提供方约束；具体地址解析和版本适配只维护在代码与测试。

## 读取结果

洞天 Runtime 应区分并计时：

- 进程发现；
- Manager/模型根解析；
- `Model.Data` 结构验证；
- 业务快照解码。

返回值至少表达行动力、完整性、观测时间、阶段耗时和类型化失败。正确但超过业务窗口的快照仍属于运行失败，不能把性能问题伪装成业务成功。

## 复用

- 首次完整读取可以同时建立敌对地点计划。
- 同一有效进程中的后续轮次优先复用已验证快照/计划，只窄读行动力等会变化标量。
- PID 或进程启动代际变化后，地址和计划缓存全部失效。
- 结构验证基于稳定字段和不变量，不以 Manager 展示别名或方法集合充当唯一身份。

动作层只能消费完整、当前的快照；读取不完整时不得用 OCR 或历史抓包补成精确事实。
