# 云梦试剑页面实施清单

## 当前目标

- 建立“动态插桩采集 → 后端数据库持久化 → API 查询 → 前端展示”的云梦试剑功能。

## 关键决策

- 数据库是唯一业务事实源；页面加载不读取游戏运行态。
- 动态插桩只负责生成一次采集快照并写入数据库。
- 兑换商品以运行时 `shopItemId` 为业务主键；配置行 ID 只作为证据。同一 `shopItemId` 的多条配置需聚合限购数量。
- 活动实例不提供前端新增、删除入口，只允许 Agent/后端服务维护。
- 当前首个活动为 `8跨,2026/8/2`，历史活动按日期降序选择。
- 页面顺序固定为：资源策略、兑换宝阁、榜单情况。

## 实施项

- [x] 新增活动、兑换项、榜单数据库表与查询/写入服务。
- [x] 把本次动态插桩结果写入数据库；写入前按运行时完整数量校验，禁止把可视窗口中的少量行覆盖为完整商店。
- [x] 2026/8/2 的 8 跨活动已从 LuaJIT 运行时恢复 29 个商品，并用 ADB 核对显示顺序和聚合限购；跨服数来自 `EqualCrossGroup|210001_8` 条件并在入库时校验。
- [x] 活动选择器使用 `跨次,日期` 紧凑格式并按日期降序；页面不提供活动新增、删除入口。
- [x] 页面按资源策略、兑换宝阁、榜单情况排列；资源策略允许各活动独立配置，未配置时留空提示。
- [x] 兑换宝阁展示原序、优先级、锁定、名称、所需兑币、限购数量、总计兑币、累计兑币和还需挑战；所有表头支持升降序，且无操作列。
