# 仙市每周资源作业

## 业务目的

`仙市_每周资源` 利用祈愿与仙市刷新时间相差五小时的窗口，最大化每周免费祈愿资源收益。

- 祈愿周期在每周一 `00:00` 更新。
- 仙市免费资源库存到每周一 `05:00` 才更新。
- 仙市包含五组祈愿资源，每组两个免费项。

因此作业不是普通的“每周领取一次”，而是一个跨两个刷新时点的幂等闭环。

## 两个阶段

### 周一 00:00–05:00

祈愿已经进入新周期，仙市仍是上一周库存。上一轮在仙市中保留的资源，正好对应本周祈愿；本阶段领取这些保留项。

幂等终态：旧库存中不再存在免费项。作业每次从当前库存重新判断；已经达到终态时零动作结束。

### 周一 05:00 以后

仙市刷新为新一周库存。作业保留“下一周祈愿”对应组的两个免费项，领取其余四组免费项，供下周 `00:00–05:00` 窗口使用。

幂等终态：仙市中不再存在“下一周祈愿组之外”的免费资源；正常完整库存会剩下该组两个免费项。通常从完整的新库存收敛到终态会领取八项，但“本次领取八项”不是完成条件；任意中间状态都应依据当前库存继续收敛。

## 判断原则

1. 当前游戏页面是业务事实来源，不维护独立的“已领取”业务账本，也不依赖上一次执行过程或日志是否完整。
2. 每次动作后重新读取仙市免费项集合，持续向阶段终态收敛。
3. 商品名称需要按祈愿资源组分类；短暂飘字或遮挡应在原地复核。
4. OCR 集合不完整、分类未知或领取后落点未确认时，不得推进到下周；写入短重试时间后正常结束本次 Task。
5. 已达到阶段终态时，即使本次没有执行领取动作，也属于合法的幂等完成；处于任意中间状态时，从当前事实继续收敛。

## 调度边界

Scheduler 只根据 `next_time` 触发作业。阶段判断、终态判断、短重试以及下周时间都由 Task 自己计算并写入。
