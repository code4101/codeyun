# 凡修重复槽位对齐标注方法

## 问题背景

GUI 中经常存在具有对称性或重复结构的元素组，例如阵容职业、背包格子、任务卡片按钮、列表行内固定图标。它们在视觉上属于同一组控件，通常满足同尺寸、同 y 或同 x、固定间距等几何规律。

人工逐个画框只能得到粗标。粗标可以表达“目标大概在哪里”，但很难保证每个框像素级对齐。如果后续标准算法直接消费这些粗框，模板匹配、局部裁剪、置信度比较都会被几何误差污染，尤其是小图标、小文字、重复槽位这类目标。

因此这类标注需要从“粗标”进一步处理成“精标”：先用人工框提供候选范围，再利用元素组的几何对称性自动对齐，生成一组标准、等距、同尺寸的 shape。

## 基本模型

对一排等距槽位，精标后只需要两个信息：

- 排头元素的标准框：`x1, y1, x2, y2`
- 相邻槽位间距：`step`

其余槽位按公式生成：

```text
slot_i.x1 = base.x1 + step * (i - 1)
slot_i.y1 = base.y1
slot_i.x2 = base.x2 + step * (i - 1)
slot_i.y2 = base.y2
```

如果是竖向重复，则把 `step` 应用到 y 方向。核心是：先确定一个排头锚点，再用标准间距派生同组其他 shape 的坐标。

## 自动校准

人工只需要画出粗框。算法应在粗框附近做局部搜索，找到模板最高相似度位置，再把这个位置作为排头标准框。

如果静态图里存在两个相同元素，可以把它们作为几何锚点。例如 #309 里存在两个职业都是 `体`，可以用第一个 `体` 作为模板，在整条 `我方职业` 区域里搜索。最高的两个同类峰值分别对应第 `i`、`j` 槽，由此得到标准间距：

```text
step = (x_j - x_i) / (j - i)
```

如果两个相同元素刚好是第 1、4 槽，则 `step = (x4 - x1) / 3`；如果新帧里相同元素是第 1、2 槽，则 `step = x2 - x1`。得到 `step` 后，以排头标准框为锚点，直接生成第 2-5 个槽位的坐标。这样后续 shape 天然同 y、同尺寸、等间距，而不是依赖 5 个手工粗框各自的误差。

## 运行时识别

运行时不要硬依赖人工粗框。推荐流程是：

1. 使用校准后的标准槽位框。
2. 对每个槽位在附近做小范围滑窗匹配。
3. 对候选职业模板取最高分。
4. 如果最高分过低，或第一名与第二名差距太小，归为 `其他/不确定`。

业务层只消费最终结构化结果，例如：

```python
["体", "剑", "体", "法", "魔"]
```

校准、滑窗、置信度判断应留在通用识别工具里，不写进具体日常任务流程。
