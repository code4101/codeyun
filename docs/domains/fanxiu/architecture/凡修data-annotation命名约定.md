# 凡修 data-annotation 术语契约

## 核心术语

- **场景帧 scene/frame**：资产树中用于描述一个可识别界面状态的节点。
- **直播帧**：运行时从模拟器获得的当前图像，不叫 scene。
- **Shape**：scene 内的身份、动作、局部结构、识别区或参数化区域。
- **资产树**：scene 与 Shape 的编辑和存储结构。
- **识别图**：由 scene 身份关系和动作后继关系形成的运行模型。

业务代码、公开 API 和日志优先使用 `scene`。view 是旧版兼容名称，只保留 `wait_view()` 等兼容入口；新代码使用 `wait_scene()` 和 `go_scene()`。

## 分组

资产树一级业务分组遵循主干定义：遮挡、弹窗、场景、日常、周常、资源、日程、活动。目录只表达业务组织，不自动生成识别关系或运行优先级。

## 命名原则

- 名称表达用户可理解的界面或动作语义，不写实现算法。
- 同名 Shape 必须能通过父路径或 scene 唯一消歧；运行时不得默选第一个。
- scene 编号是资产身份，不是业务优先级、恢复策略或类型系统。
- 新术语先确认是否已由代码类型或主干定义，避免 scene/view、task/job 等平行词继续扩散。
