# 凡修抓包服务契约

抓包服务是接口层的事实生产者，不是页面功能、Job 调度器或业务决策器。

## 数据流

```text
原始 capture segment
  → 有序解析
  → 协议事实
  → 业务归一化写入器
  → 数据库当前事实/历史
  → API 与页面只读查询
```

## 边界

- 采集、解析、业务归一化和展示查询分别拥有自己的状态与错误。
- 实时处理与历史补扫复用同一解析和写入核心；补扫不得倒灌覆盖更新水位。
- 图鉴或详情页禁止触发抓包、解析、同步、重建或历史补扫。
- 行为树可以读取已落库事实或显式等待水位，但不管理抓包进程和解析队列。
- 抓包缺失、解码不完整、业务映射未知和页面投影错误必须区分。
