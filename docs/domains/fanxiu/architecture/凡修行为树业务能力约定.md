# 凡修行为树公共能力契约

业务 Task 组合公共语义动作，不重复实现坐标、滚动、OCR、场景判断和恢复算法。

## 公共能力

- `go_scene()`：从当前可靠 scene 出发，逐动作执行并按真实落点重规划。
- `wait_scene()`：等待候选 scene；超时返回明确失败，不做全树重型诊断。
- `wait_click()`：在 scene/Shape 语义下等待、定位、点击并验证直接结果。
- 局部 OCR/结构读取：只能在已标注 Shape 范围内消费文字和 token。
- 滚动查找：每次滚动后读取新帧、判断是否移动、去重已见内容，并以边界/循环/超时结束。

## 业务实现要求

- Task 只表达业务目标、准入、完成判据和动作顺序。
- 不写死坐标、滚动次数、私有 OCR 规则或借用其它 scene 的 Shape。
- 公共能力不足时修底座并增加回归，不在单个 Task 旁路实现。
- 不可逆动作前验证身份、资源、次数和授权；动作后用业务事实复验。

函数签名、选项和返回类型以运行时代码、类型和测试为准。
