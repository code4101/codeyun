# 凡修 MuMu 模拟器异常恢复

## 适用场景

仅用于模拟器进程失联、ADB 不可用、画面冻结、游戏进程退出或资源压力导致的基础设施异常。业务 scene 不匹配、Job 失败和数据未加载不自动升级为模拟器重启。

## 恢复顺序

1. 只读确认 Kernel、当前 Cell、Scheduler 运行权、ADB 与游戏进程状态。
2. 如果仍有 Cell 运行，先按精确 interrupt 契约终止并确认结束。
3. 优先恢复 ADB 或游戏进程；只有模拟器本体异常时才重启 MuMu。
4. 等待 ADB 唯一设备、游戏进程和稳定直播帧恢复。
5. restart 凡修 Kernel，使进程地址和运行时代际缓存全部失效重建。
6. 确认 Kernel idle、工程模式和作业清单仍一致，再恢复 Scheduler。

## 禁止

- 不用 Android Back/Esc 修复基础设施。
- 不在旧 Cell 未终止时强行重启并重放。
- 不把端口短暂不可达直接判为模拟器失败。
- 不使用 WMI 全量扫描进程命令行；按仓库 `AGENTS.md` 使用轻量进程和端口探针。
- 不因恢复基础设施而自动补跑可能有不可逆副作用的旧中间步骤。

具体启动命令、进程名和端口由当前 MuMu/ADB 控制代码维护，本文不保存易漂移命令清单。
