# 通用投入产出价值评估模型

> 基于成本、产出价值与时间的三变量评估框架

## 1. 文档定位

本文定义一套与具体业务无关的投入产出价值评估模型。凡是能够量化投入成本、产出价值与处理时间的过程，都可以映射到同一组基础变量，并得到统一、可解释的评价指标。

模型只回答三个问题：

1. 每单位成本可以换回多少价值？
2. 完成一次过程可以获得多少净利润？
3. 每单位时间可以产生多少净利润？

炼丹与股票只是本文最后用于验证模型解释力的两个应用案例，不参与通用模型本身的定义。

## 2. 设计原则

### 2.1 基础事实与派生指标分离

成本、价值与时间是外部业务提供的基础事实；产出比、净利润与时利润是由公式计算得到的派生指标。派生指标不应作为第二份业务事实重复存储。

### 2.2 价值计算与决策排序分离

价值模型负责计算指标，排序程序负责表达使用者当前更重视哪个指标。调整排序优先级不会改变模型及其计算结果。

### 2.3 理论模型与应用案例分离

业务对象只负责把自身数据映射为成本、价值与时间。模型不应包含炼丹规则、股票交易规则或其他领域专用字段。

## 3. 完整三变量模型

### 3.1 基础变量

设：

- \(C\)：成本（Cost），表示一次过程消耗的全部可计价投入；
- \(V\)：产出价值（Value），表示一次过程完成后得到的全部可计价价值；
- \(T\)：时间（Time），表示完成一次过程所需的时间。

基础定义域为：

\[
C > 0, \qquad T > 0
\]

\(C\) 与 \(V\) 必须使用同一价值单位，\(T\) 必须使用当前比较范围内一致的时间单位。

### 3.2 派生指标

设：

- \(R\)：产出比（Output–Input Ratio）；
- \(P\)：净利润（Net Profit）；
- \(Q\)：时利润，即利润速率（Profit Rate）。

则：

\[
R = \frac{V}{C}
\]

\[
P = V - C
\]

\[
Q = \frac{P}{T} = \frac{V-C}{T}
\]

完整模型写为：

\[
\mathcal{E}(C,V,T) = (R,P,Q)
\]

默认输出顺序为：

```text
产出比 → 净利润 → 时利润
```

这个顺序表达“投入效率 → 单次收益 → 时间效率”的阅读路径，不表示三个输入与三个输出之间存在逐项一一对应关系。

### 3.3 指标含义

#### 产出比

\(R\) 回答“每投入 1 单位成本，可以得到多少单位产出价值”。例如 \(R=3.5\) 表示每投入 1 单位成本，可以得到 3.5 单位价值。

本文使用“产出比”，不使用含义较宽泛的“性价比”。它在成本效益分析中接近 Benefit–Cost Ratio。由于

\[
\frac{P}{C} = \frac{V-C}{C} = R-1
\]

净收益率 \(P/C\) 与产出比 \(R\) 永远产生相同排序，因此模型只保留更直观的产出比。

#### 净利润

\(P\) 回答“完成一次过程实际增加多少价值”。它保留绝对规模信息，因此可能与产出比产生不同排序。

#### 时利润

\(Q\) 回答“每单位时间产生多少净利润”。“时利润”是本文采用的紧凑名称，其中“时”表示单位时间，不固定指小时。

在具体业务中，应根据时间单位显示为“日利润”“小时利润”“月利润”或“回合利润”；代码和正式数学语义统一使用利润速率 `profit_rate`。

## 4. 稳定流降维模型

### 4.1 降维条件

对于长期稳定、随时间等比例增长的流过程，绝对累计成本、绝对累计价值与绝对累计利润依赖任意选择的时间长度，本身不再是稳定的比较坐标。

若时间扩大 \(\lambda\) 倍，则：

\[
(C,V,T) \mapsto (\lambda C,\lambda V,\lambda T), \qquad \lambda>0
\]

此时产出比与利润速率保持不变，而累计量随时间等比例增长。稳定流因此可以按单位时间归一化。

### 4.2 单位时间归一化

定义：

- \(c=C/T\)：单位时间成本；
- \(v=V/T\)：单位时间产出价值。

令一个单位时间为标准时间：

\[
T=1
\]

稳定流的两个核心坐标可以取为单位时间成本 \(c\) 与产出比 \(R\)。其余变量均可恢复：

\[
V = cR
\]

\[
P = c(R-1)
\]

\[
Q = \frac{P}{1}=c(R-1)
\]

因此，稳定流的标准化完整表示为：

\[
(C,V,T)=(c,cR,1)
\]

\[
(R,P,Q)=(R,c(R-1),c(R-1))
\]

稳定流本质上从完整三变量模型降为由 \((c,R)\) 决定的二维模型。标准化后，净利润与时利润数值相同，是因为净利润被限定在一个单位时间内；两者语义仍然分别表示“该标准时间段内的利润量”与“利润速率”。

### 4.3 时间缺失的解释

当业务对象表达的是稳定流，且没有提供独立时间长度时，默认采用单位时间归一化：令 \(T=1\)，把成本和价值解释为单位时间量，再补全六个变量。

这不是增加新的时间变量，而是为同一个稳定流选择标准化表示。

“过程永远无法完成”属于退化的不可行情况，不作为稳定流处理，也没有必要进入常规价值排序。

## 5. 排序决策模型

价值模型固定输出 \((R,P,Q)\)，实现层允许调整三个指标的优先顺序。排序采用字典序：先比较第一指标，结果相同时再比较第二指标，前两项仍相同时再比较第三指标。

默认排序程序为：

```text
1. 产出比 R，降序
2. 净利润 P，降序
3. 时利润 Q，降序
```

典型策略包括：

| 排序程序 | 决策含义 |
| --- | --- |
| 产出比 → 净利润 → 时利润 | 优先投入效率 |
| 净利润 → 产出比 → 时利润 | 优先单次绝对收益 |
| 时利润 → 产出比 → 净利润 | 优先长期生产速度 |

字典序排序不引入人为权重，不把不同量纲强行混合成一个综合分。理论模型中的输出顺序只是默认约定；用户调整排序程序不会修改任何基础事实或派生公式。

## 6. 边界条件

### 6.1 零成本

当 \(C=0\) 时，产出比 \(V/C\) 未定义。此类对象应标记为“零成本”并单独处理，不能用任意大数替代产出比参与普通排序。

### 6.2 零时间

当 \(T=0\) 时，时利润 \(P/T\) 未定义。除非业务明确存在瞬时过程，否则通常表示时间数据无效。

### 6.3 时间未知与稳定流

批次过程的耗时未知时，不能计算时利润；稳定流未提供时间长度时，则采用第 4 节的单位时间归一化。两者的业务语义不同，不能只凭字段为空自动混为一类。

### 6.4 负利润

当 \(V<C\) 时，\(R<1\)、\(P<0\)、\(Q<0\)。模型应保留负值，因为亏损程度本身仍有比较意义。

### 6.5 不确定性

基础模型是确定性模型。价格波动、失败概率、风险、稀缺性、流动性、并行产能和机会成本需要在业务层先转化为可比较的 \(C\)、\(V\)、\(T\)，或在未来扩展为期望值、分布与约束模型。

## 7. 应用案例一：炼丹

炼丹是确定性的离散批次生产案例。

映射关系：

- \(C\)：实际使用药材的总价值；
- \(V\)：最终成丹数量乘以丹药单位价值；
- \(T\)：该次炼制所需天数；
- \(R\)：产出比；
- \(P\)：单炉净利润；
- \(Q\)：日利润。

例如：

\[
C=60,\qquad V=210,\qquad T=3\text{ 天}
\]

则：

\[
R=\frac{210}{60}=3.5
\]

\[
P=210-60=150
\]

\[
Q=\frac{150}{3}=50/\text{天}
\]

同一种丹药的所有方案若炼制时间相同，则按净利润与按日利润排序等价；只有比较不同炼制时间的丹药、丹炉或方案时，日利润才提供新的排序信息。

炼丹的五行配平、药材形状、阴阳炉摆放、成丹规则与配方求解均属于业务求解层。它们负责产生候选方案及其 \((C,V,T)\)，不进入通用价值模型。

## 8. 应用案例二：股票

股票案例用于说明模型如何评价一段已发生或假设确定的资产过程，而不是预测未来价格。

映射关系：

- \(C\)：买入成本及交易费用；
- \(V\)：卖出价值、分红及其他持有期现金收益之和；
- \(T\)：持有时间；
- \(R\)：产出比；
- \(P\)：该段持有过程的净利润；
- \(Q\)：单位持有时间的绝对利润。

例如：

\[
C=10000,\qquad V=11200,\qquad T=120\text{ 天}
\]

则：

\[
R=1.12,\qquad P=1200,\qquad Q=10/\text{天}
\]

股票的价格不确定性、波动率、回撤、风险调整收益与复利增长不属于本基础模型。若用于预测性评估，应先把 \(V\) 扩展为随机变量或期望价值，并另行增加风险约束；不能把风险偷偷折入一个无法解释的综合权重。

## 9. 实现约定

通用实现只需要接受三个基础事实，并即时计算三个派生指标：

```text
输入：
  cost              成本 C
  value             产出价值 V
  duration          时间 T

输出：
  output_input_ratio 产出比 R
  net_profit         净利润 P
  profit_rate        时利润 Q
```

稳定流可以使用单位时间数据调用同一模型：

```text
duration = 1
cost     = 单位时间成本
value    = 单位时间产出价值
```

排序优先级应作为独立的排序程序保存，不进入价值模型输入，也不产生额外的“综合价值”字段。

## 10. 结论

通用投入产出价值评估模型以三个基础事实

\[
(C,V,T)
\]

派生三个评价指标

\[
(R,P,Q)
\]

并通过独立、可重排的字典序排序程序表达不同决策偏好。对于稳定流，模型通过单位时间归一化降为由单位时间成本与产出比决定的二维形式，不需要增加其他变量。

这套结构保持了事实、计算、决策与业务案例之间的正交性，可作为制造、加工、交易、生产与任务收益评估的统一基础模型。
