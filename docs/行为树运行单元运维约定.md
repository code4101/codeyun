# 行为树运行单元运维约定

凡修部分不在本文重复定义。请以 [凡修行为树运行框架约定](./凡修行为树运行框架约定.md) 为唯一事实源。

凡修运维只使用以下 Jupyter 语义：

- cell：向当前 Kernel 提交普通 Python Cell。
- interrupt：中断当前 Cell，保留 namespace。
- restart：替换 Kernel，清空 namespace，并重新加载凡修框架。
- shutdown：终止 Kernel。

Runtime 业务状态与 Kernel 的 idle / busy / dead 是两个正交维度。Scheduler 的触发时间、重试、优先级与模拟器仲裁不进入 Kernel。

其他项目的行为树服务若采用不同运行模型，应在其项目专属文档中说明，不得借用凡修的 Kernel / Cell 术语制造第二套凡修执行路径。
